# Neighbourhood — website

Website for **Neighbourhood**, Kitchen & Coffee Bar, 134 Saket Nagar Main Road, Indore ([@neighbourhood.idr](https://www.instagram.com/neighbourhood.idr/)).

- `index.html` — the whole site, self-contained (fonts, photos and illustration embedded). Static, no build step.
- `assets/photos/neighbourhood-team.webp` — team photo used in Our Story (loaded from file).
- `assets/` — source files for edits: cleaned façade illustration, auto-rickshaw (editable SVG, from the supplied vector, recoloured to Indore green and yellow), logo.

Hero: watercolour façade blended into the page, auto-rickshaw that stops at the gate, a dog on the steps, the wall logo spreading in like ink, lamps after 7 pm Indore time. Lenis smooth scroll. Reduced-motion respected.

Hosting: GitHub Pages, branch `main`, folder `/ (root)`.

Designed by Beyond Branding · thebeyondbranding.com

Location: 134 Saket Nagar Main Rd, Indore 452018 (22.725848, 75.8974009). The Visit map loads the live Google map on the hosted site.
